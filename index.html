Projects

A series of browser-based exploratory spatial data analysis tools, built with D3.js. Each takes the linked-view brushing model from GeoDa — select features in one view and watch them highlight in the others — and makes it work on the open web with no install and no build step. All three are data-agnostic: point the config file at your own GeoJSON and the tool adapts.

Choropleth EDA — Univariate

A classified choropleth linked to a histogram of the mapped variable. Lasso or rectangle-select features on the map to see where they fall in the distribution, or brush a range in the histogram to see where those features are. Quantile and equal-interval classification, 3–8 classes, 27 ColorBrewer palettes, and a summary statistics panel comparing the selection to the full population.

Live demo Source Demo data: NYC census tracts, 2020

Choropleth EDA — Bivariate

A 3×3 bivariate choropleth linked to a scatterplot with OLS regression. Selecting a subset draws a second regression line for that subset, so you can compare its slope and correlation against the full population directly. Six bivariate color schemes adapted from Joshua Stevens, with a floating color-matrix legend showing the class breaks.

Live demo Source Demo data: NYC COVID-19 vaccination rates by MODZCTA, 2021

Choropleth EDA — Two Maps

Two stacked choropleths with independent variables, palettes, and legends, sharing synchronized zoom and pan, plus a scatterplot of one against the other. Selection in any of the three views propagates to the other two. The layout divider is draggable, so the balance between map and chart is yours to set.

Live demo Source Demo data: NYC COVID-19 vaccination rates by MODZCTA, 2021
